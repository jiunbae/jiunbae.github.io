개인정보 처리방침

시행일: 2026년 11월 16일 (같은 날 수정)

요약: Doki에는 계정도, 광고도, 분석·추적 SDK도 없습니다. 대화와 기억은 기기에 저장됩니다. 답변은 기기 안에서 만들어지며, 사용자가 직접 클라우드 모델이나 에이전트 서비스를 고른 경우에만 답변에 필요한 내용이 그 제공업체로 바로 전송됩니다. 개발자는 사용자의 대화를 받지 않습니다.

1. 기기에 저장되는 것

대화, 캐릭터가 대화에서 간직하는 장기 기억, 캐릭터, 앱 설정, 내려받은 모델 파일이 기기에 저장됩니다. iPhone에서는 기억 저장소가 기기 백업에서 제외됩니다.

2. 기기 내 모델

Apple Intelligence나 내려받는 Gemma 모델을 쓰면 답변과 기억이 기기 안에서 만들어집니다. Gemma 모델을 내려받을 때는 공개 모델 저장소에서 모델 파일만 받아 오며, 대화 내용은 전송되지 않습니다.

3. 직접 고른 클라우드 모델 (iPhone)

iPhone에서는 클라우드 모델 제공업체(예: Anthropic, OpenAI, OpenRouter, 직접 운영하는 서버)의 API 키를 직접 등록하거나, 기기 내 모델이 실패했을 때 클라우드로 다시 시도하도록 허용할 수 있습니다. 이때 메시지, 최근 대화, 캐릭터 설정, 관련 기억이 사용자의 키로 기기에서 해당 제공업체로 바로 전송되며, 그 업체의 약관이 적용됩니다. API 키는 iOS 키체인에 저장됩니다. 사용자가 허용하지 않으면 클라우드 모델로 아무것도 전송되지 않습니다.

4. 직접 고른 에이전트 서비스 (Mac)

Mac에서는 설치해 둔 Claude Code나 Codex를 통해 캐릭터가 답하게 할 수 있습니다. 이때 요청, 캐릭터 설정, 해당 에이전트와의 대화가 사용자 본인 계정으로 그 서비스에 전송됩니다. 에이전트는 사용자가 고른 작업 폴더나 직접 설정한 로컬 컨테이너·원격 머신에서 실행되며, 그곳의 파일을 읽을 수 있고(편집을 허용하면 수정도 합니다), 읽은 내용은 그 서비스로 전송될 수 있습니다. 기기 내 모델과 나눈 대화와 장기 기억은 전송되지 않습니다.

5. 화면·활동 인식 (Mac, 선택 사항)

'작업 화면 함께 보기'를 켜고 권한을 허용하면, Doki는 Apple Intelligence·Gemma 대화가 최근 작업 맥락을 참고할 수 있도록 약 15초마다 Mac의 맨 앞 앱 창을 글자 인식과 손쉬운 사용 정보로 읽습니다. 이 내용은 Mac 안에서만 처리되며, 캡처는 파일로 저장되지 않고 이를 쓴 대화는 장기 기억에 남지 않습니다.

Claude Code나 Codex를 쓸 때 화면에 대해 물으면 에이전트가 현재 앱 창의 글과 화면 이미지를 읽는 도구를 쓸 수 있고, 읽은 내용은 선택한 서비스로 전송됩니다. 이 도구는 기본으로 켜져 있고 '작업 화면 함께 보기'를 꺼도 쓸 수 있으며, 손쉬운 사용·화면 기록 권한이 필요하고 설정에서 끌 수 있습니다. 화면에 클릭이나 입력을 보내지는 않습니다.

작업 맥락 설정을 켠 경우에만, Doki는 조용히 있어야 할 때를 고르기 위해 Mac 안에서 다음 신호를 씁니다. 입력이 없던 시간, 키 입력 여부(어떤 키인지가 아니라 시간만), 맨 앞 앱의 종류와 사용 시간, 앱 전환과 종료입니다. 이를 위해 입력 내용·앱과 창 제목·문서·화면 내용을 읽지 않고, 이 정보는 Mac 밖으로 보내지 않으며, 보안 입력 중에는 관측을 쉽니다. 이와 별개로 쉬기·졸기와 말 걸기에는 기본 입력 공백 시간(숫자만)을 항상 사용합니다.

6. 마이크와 음성

마이크는 권한을 허용하고 말하기를 시작한 뒤에만 사용합니다. 음성은 기기 안에서 글로 바뀌며 서버로 전송되지 않습니다.

7. 분석, 광고, 추적

  • 광고 SDK와 분석 SDK가 없습니다.
  • 다른 회사의 앱이나 웹사이트에 걸쳐 사용자를 추적하지 않습니다.
  • 개인정보를 판매하지 않습니다.
  • 계정이 필요 없습니다.

TestFlight로 테스트 빌드를 설치하면 Apple의 TestFlight 약관에 따라 Apple이 충돌·사용 정보를 수집해 개발자와 공유할 수 있습니다. TestFlight로 보낸 피드백은 개발자에게 전달됩니다.

8. 데이터 삭제

앱에서 대화를 지울 수 있으며, 이때 장기 기억은 남습니다. iPhone에서 앱을 삭제하면 앱의 데이터도 삭제됩니다. Mac에서는 데이터가 사용자 계정의 ~/Library/Application Support/Doki 폴더에 보관되며, 이 폴더를 지우면 대화와 기억이 삭제됩니다.

9. 어린이

Doki는 만 13세 미만 어린이를 대상으로 하지 않습니다.

10. 변경

Doki가 바뀌면 이 방침도 바뀔 수 있습니다. 중요한 변경은 새 시행일과 함께 이 페이지에 반영됩니다.
